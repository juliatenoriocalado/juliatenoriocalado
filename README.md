## Projetos em destaque

### 🎬 CineData Analytics: engenharia de dados e preparação para IA
Pipeline de ETL em **Databricks (PySpark + SQL)** na **Arquitetura Medalhão** (Bronze → Silver → Gold), com ingestão, limpeza, deduplicação e conversão de valores USD → BRL via API do Banco Central. Modelagem em **Star Schema** e geração de contexto consolidado para aplicações com **LLM, Vector Search e RAG**. Orquestrado com Databricks Workflows.
`Databricks` `PySpark` `SQL` · [Repositório](https://github.com/juliatenoriocalado/Engenharia-de-Dados-RocketLab)

### 🎞️ Sistema de Avaliação de Filmes (full-stack)
API em **FastAPI + SQLAlchemy + SQLite** com CRUD, busca, paginação, avaliações e cálculo de médias, integrada a um front-end em **React + TypeScript**.
`FastAPI` `SQLAlchemy` `React` `TypeScript` · [Repositório](https://github.com/juliatenoriocalado/RocketLab-Desafio2)

### 💊 Arca Gênesis: back-end
APIs e regras de negócio em **Django**, com camada de serviços para centralizar cálculos de dosagem e conversões, modelagem com constraints e migrations, e **testes automatizados** cobrindo limites e exceções. Desenvolvido em sprints, com branches e Pull Requests.
`Python` `Django` `PostgreSQL` · [Repositório](https://github.com/pedrovcb/genesis)

### 👗 DRESScode: plataforma de guarda-roupa digital 🏆
Aplicação web full-stack para organizar peças e montar combinações de looks. Testes automatizados com **Selenium**, **CI/CD** e deploy em produção no **Render**. Premiado na Mostra TechDesign 2026.1 (categoria IHC).
`Django` `PostgreSQL` `Selenium` `CI/CD` · [Repositório](https://github.com/beatrizloyola/DRESScode)

### 📚 README: gerenciamento de acervo bibliotecário
Sistema web para o acervo acadêmico, com back-end em **Django + PostgreSQL**, imagens e arquivos com **Cloudinary**, protótipos no **Figma**, gestão ágil no **Jira** e deploy no **Azure**.
`Django` `PostgreSQL` `Azure` · [Aplicação no ar](https://readme.azurewebsites.net/)

### 🎪 Carnival Story: jogo 2D de ação e boss rush, em C
Arquitetura com **máquina de estados finita**, entidades gerenciadas com **listas encadeadas** e controle rigoroso de memória (malloc/free), física 2D, IA de chefes com padrões de ataque compostos e sistema de combo/parry.
`C` `Raylib` `Estruturas de dados` · [Repositório](https://github.com/juliatenoriocalado/PROJETO-PIF)

### ⚙️ Sistemas em C (Linux)
- **ProcessFlow**: orquestrador de processos com pipelines, redirecionamento de E/S, jobs em background e execução paralela. [Repositório](https://github.com/juliatenoriocalado/Atividade_01_IS_jtc)
- **Mandelbrot paralelo**: versões serial, OpenMP e Pthreads, com comparação de desempenho. [Repositório](https://github.com/juliatenoriocalado/Atividade_02_IS_jtc)
